Hi.I wanted to get some experience animating characters for video games. So I made these animations for my super heroine model, using Blender.

I rigged the model using the Rigify addon, adding two more simple tentacle samples to the metarig, in order to control the hair and the cape.

Then, I imported these animations into Redot Engine, and used a CharacterBody3D with an Animation Tree and a script to create the characters control
